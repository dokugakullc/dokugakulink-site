# public/ads — 広告入稿用の公開ファイル

広告サービスへ公開URLから素材を渡す必要がある場合に使用する配信ディレクトリです。

画像制作の正本は `assets/marketing/meta-ads/creatives/` に置き、
このディレクトリには公開URLとして必要なファイルだけを複製します。

## 2026-08

- `ukareru/2026-08/product-proof-v2-4x5.png`
  - 正本：`assets/marketing/meta-ads/creatives/2026-08_appstore_launch/ad_waitlist_product_proof-v2-4x5.png`
- `ukareru/2026-08/problem-solution-v2-4x5.png`
  - 正本：`assets/marketing/meta-ads/creatives/2026-08_appstore_launch/ad_waitlist_problem_solution-v2-4x5.png`

複製時は正本とのハッシュ一致を確認してください。

広告サービスへの入稿後も、既存URLの継続性とデプロイの再現性を保つため、
Ownerの承認なしに配信ファイルを削除しないでください。
