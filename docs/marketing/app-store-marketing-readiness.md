# ウカレル App Store提出素材 マーケティング確認表

実機QAの技術判定は開発担当が行う。この文書では、ユーザーに見える提出素材とLP・広告の整合だけを確認する。

## 提出前に確定する素材

- アプリ名
- サブタイトル
- App Store説明文
- キーワード
- プロモーションテキスト
- App Storeスクリーンショット
- Appアイコン
- サポートURL
- マーケティングURL
- プライバシーポリシーURL
- 料金・無料範囲・アプリ内課金の説明
- 審査担当者向けの操作説明

## ウカレルで統一する事実

- 対象資格：宅地建物取引士（宅建）
- 収録問題：913問（提出ビルドとの一致を最終確認する）
- 登録から30日間、すべての学習機能を無料で利用できる
- 30日後も「今日の15問」と学習履歴は無料で利用できる
- 無料期間の終了を理由に自動で課金されない
- プレミアムプランは月額580円（税込）
- プレミアム加入後は解約まで自動更新される

## Build 15で実装根拠を確認した訴求

- 今日やるべき15問の提示
- 復習対象と復習タイミングの管理
- 分野別の理解度・苦手分析
- 合格可能性と現在地の表示
- 問題解説
- 学習履歴・積み重ねの表示

合格可能性は回答データが一定量蓄積してから表示される。初回起動直後から表示されるようなスクリーンショットや説明にしない。

## スクリーンショット確認

- 最新の提出ビルドと画面が一致している
- 開発用データ、個人情報、デバッグ表示が写っていない
- 合格可能性を合格保証のように表現していない
- 実際には表示条件がある機能を、初回から使えるように誤認させない
- 「科学的に最適」「必ず覚えられる」など未立証の表現を使っていない
- LP、広告、App Storeで「今日の15問」の表記が一致している

## 公開直前の導線確認

- App Store URLを取得した
- LPの事前登録CTAをApp Store導線へ切り替える時期を決めた
- 事前登録者向け公開メールへ正しいURLを設定した
- Meta広告のリンク先とUTMを確認した
- 公開前の確認広告と、公開後のインストール広告を混同していない
